FAQ

Perguntas frequentes.

Respostas claras para facilitar sua decisão.

Como comprar?

Escolha sua categoria, produto e quantidade. Use a sacola para conferir os itens e siga para a etapa de pedido.

Como funcionam os cupons?

Abra “Cupons”, copie um código disponível e utilize-o no fluxo de compra quando o checkout estiver conectado. A validade visual desta campanha é 10/10/2026.

Como acompanho meu pedido?

Abra “Pedidos feitos”. O histórico é armazenado neste navegador quando um pedido é registrado pelo fluxo do site.

Como falar com a DonnaBella?

Use a Central de atendimento. O chat funciona como interface local; para contato real com a equipe, conecte o formulário a um e-mail, WhatsApp ou serviço de atendimento.

Onde encontro a política de privacidade?

Acesse a página de política no rodapé.
